# 🃏 Memory Card Game

A classic memory matching game built with HTML, CSS, and JavaScript. Test your memory skills by matching pairs of cards in the fewest moves possible!

## ✨ Live Demo

[Play the Memory Game](https://sola-man.github.io/memory-card-game)

## 🎮 How to Play

1. Click on any card to flip it over
2. Click on a second card to find its match
3. If the cards match, they stay flipped
4. If they don't match, they flip back after 1 second
5. Match all 8 pairs to win!
6. Try to complete the game in the **fewest moves possible**

## 🎯 Features

- **8 Matching Pairs** - 16 cards total (emoji-based)
- **Move Counter** - Track how many attempts you've made
- **Match Counter** - See your progress in real-time
- **Win Message** - Celebration message when you complete the game
- **Reset Button** - Start a new game anytime
- **Responsive Design** - Plays great on desktop and mobile
- **Smooth Animations** - Flip effects and match feedback

## 🛠️ Technologies Used

- **HTML5** - Structure and layout
- **CSS3** - Styling, grid layout, animations, responsive design
- **JavaScript (ES6+)** - Game logic, event handling, DOM manipulation
